## 🔌 インテグレーション
| ツール | お問い合わせ
|---|---|
| [WebUIを開く](https://github.com/open-webui/open-webui) | セルフホスト型チャットGPT型UI |

| 【LiteLLM】(https://github.com/BerriAI/litellm) | One API → 100+ プロバイダー |

> ローカルはなぜですか? プライバシー・ファースト、オフライン、トークンごとのゼロコスト。 [Snitch](https://github.com/aixisstudio/Snitch)を*prove*によくペアは、マシンを離れません。

## モデルのサイズと使用

| モデル | サイズ | 最良 |
|---|---|---|
| Llama 3.3 70B | 40GB+ | ベストオープン品質 |
| Qwen 2.5 72B | 45GB+ | 多言語コーディング |
| ミストラルスモール3 | 14GB | スウィートスポット24B |
| Phi-4 | 9GB | マイクロソフトの14B | 素晴らしい理由 |
| ジェムマ 2 9B | 6GB | 早くても良い |
| Qwen 2.5 3B | 2GB | ノートパソコン対応 |
| Llama 3.2 1B | <1GB | 電話番号 |
